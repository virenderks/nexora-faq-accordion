
# NEXORA FAQ Accordion
An interactive and responsive FAQ component built using HTML, CSS and Vanilla JavaScript.

## 🌐 Live Demo

https://virenderks.github.io/nexora-faq-accordion/


## Project Overview

NEXORA FAQ Accordion is an interactive Frequently Asked Questions component developed using HTML5, CSS3, and vanilla JavaScript.

It allows users to expand and collapse FAQ answers through a simple and responsive interface.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Interactive FAQ accordion.
- Single-open accordion functionality.
- Smooth opening and closing animations.
- Responsive design for desktop and mobile devices.
- Keyboard accessibility.
- ARIA attributes for screen readers.
- Error handling for missing HTML elements.
- Reduced-motion support.
- No external libraries or frameworks.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. The FAQ accordion will open in your browser.

You can also open index.html directly in a modern web browser.

## How to Use

1. Click any FAQ question to view its answer.
2. Click another question to open its answer.
3. Only one answer remains open at a time.
4. Click the currently open question to close it.
5. Use Tab, Enter, and Space keys to navigate and interact.
